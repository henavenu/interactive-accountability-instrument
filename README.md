# Interactive Accountability Instrument

A practical accountability guide for agentic AI: the five-step accountability
instrument from the primer *Units of Governance: Classifying AI Agents for
Accountability*, made operable.

**Open it:** https://henavenu.github.io/interactive-accountability-instrument/

1. Classify the system: is it agentic?
2. Name the unit of governance.
3. Score agency, impact and reach; apply the two amplifiers to set the risk tier.
4. Read off the controls and assurance the tier requires (with an optional regulatory crosswalk).
5. Export the governance record (Markdown, PDF or JSON), as an agent profile or an agent passport.

Single self-contained page (`index.html`): no build step, no server, no tracking.
Only Google Fonts is loaded from the network; offline it falls back to system fonts.

Advisory guidance, not legal advice. A tier is not a legal category.
